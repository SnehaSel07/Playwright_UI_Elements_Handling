# Playwright_UI_Elements_Handling

A collection of Python Playwright scripts demonstrating UI element interactions and web automation techniques. This repository is designed to practice, learn, and showcase practical web UI automation testing skills using Playwright with Python.

## Topics Covered

- Text Input Handling
- Button Interactions
- Dropdown Handling
- Checkbox Handling
- Radio Button Handling
- Mouse Handling Events
- Frames and iFrames
- Tooltips
- Drag-and-Drop Operations
- Web Table Handling
- File Uploading
- Auto-Waiting Mechanism
- Browser Window and Tab Handling
- Allure Test Reports
- Log Generation and Management

## Tech Stack

- Python
- Playwright
- Pytest
- Allure Reports

## Objective

To build hands-on experience with Playwright UI automation, understand different locator strategies and browser interactions, and develop a foundation for creating maintainable, reliable, and scalable automation test scripts.
